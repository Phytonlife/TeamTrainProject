# 🏴‍☠️ One Piece: Доска Заказов

Проект, вдохновленный вселенной One Piece, который представляет собой "доску заказов" для команды пиратов. Участники могут брать заказы (задачи) и получать за них награду. Проект состоит из веб-сайта на Django и Telegram-бота, который отправляет уведомления в канал.

Проект развернут на **Render** и использует **UptimeRobot** для предотвращения "засыпания" бесплатного инстанса.

## 🔥 Основные возможности

### Веб-сайт
- **Доска заказов:** Главная страница отображает все активные заказы в виде "wanted"-плакатов.
- **Аутентификация:** Пользователи могут регистрироваться и входить в свой аккаунт.
- **Принятие заказов:** Авторизованный пользователь может "вызвать на бой" — взять заказ в работу.
- **Личный кабинет:** Пользователи могут привязать свой Telegram-аккаунт к профилю на сайте для получения уведомлений.

### Telegram-бот
- **Уведомления:** Бот автоматически публикует в канале сообщение, когда кто-то берет заказ.
- **Завершение заказа:** Пользователь, взявший заказ, может отметить его выполненным через команду `/complete <ID>`.
- **Информирование:** Бот публикует сообщение о выполнении заказа и начислении награды.
- **Команды:** `/start`, `/info`, `/orders`, `/my_orders`, `/link`.

## ⚙️ Технологии

- **Бэкенд:** Django 4.2+
- **Фронтенд:** Django Templates, HTML, CSS (без фреймворков)
- **База данных:** SQLite (для локальной разработки), PostgreSQL (на Render)
- **Telegram Бот:** pyTelegramBotAPI
- **Веб-сервер:** Gunicorn
- **Деплой:** Render
- **CI/CD:** render.yaml

## 🚀 Локальный запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/YourUsername/onepiece-orders.git
   cd onepiece-orders
   ```

2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # macOS/Linux
   source venv/bin/activate
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   - Скопируйте `.env.example` в новый файл `.env`.
   - Заполните все необходимые переменные (ключи, токены, ID канала).

5. **Примените миграции и создайте суперпользователя:**
   ```bash
   python manage.py migrate
   python manage.py createsuperuser
   ```

6. **Запустите сервисы:**
   - **Сайт:** `python manage.py runserver`
   - **Бот (в новом окне терминала):** `python bot/bot.py`

## ⚙️ Переменные окружения (`.env`)

Для работы проекта необходимо определить следующие переменные:

```
# Ключ для Django
DJANGO_SECRET_KEY='your-secret-key'

# Настройки для Telegram
TELEGRAM_TOKEN='your_telegram_bot_token'
CHANNEL_ID='your_channel_id_or_@username'

# Настройки для создания администратора при деплое
DJANGO_SUPERUSER_USERNAME='admin'
DJANGO_SUPERUSER_EMAIL='admin@example.com'
DJANGO_SUPERUSER_PASSWORD='strong-password'

# URL для базы данных (для Render заполняется автоматически)
DATABASE_URL=sqlite:///db.sqlite3
```
